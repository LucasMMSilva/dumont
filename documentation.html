Documentação

Introdução

O Dumont é uma biblioteca leve de componentes UI e estilos utilitários pensada para acelerar a criação de interfaces web consistentes e acessíveis. Ela reúne componentes prontos e um conjunto de tokens e mixins SCSS que facilitam a personalização visual e a integração com bundlers modernos.

Principais objetivos

  • Leveza e desempenho — componentes otimizados para produção.
  • Acessibilidade — marcação semântica e foco em usabilidade.
  • Customização — variáveis e mixins SCSS para tema rápido.
  • Documentação prática — exemplos, guias e referência de API.

Exemplo rápido

<script type="module" src="src/main.js"></script>
<dm-button>Salvar</dm-button>

dm-alert

Alerta informativo com variantes de estilo.

Atributos:

  • variant: success, warning, danger, info (default)
Operação concluída com sucesso.
<dm-alert variant="success">Operação concluída com sucesso.</dm-alert>

dm-button

Botão customizável com variantes, tamanhos e estado desabilitado.

Atributos:

  • variant: primary, secondary, success, danger, warning, info
  • size: small, medium (default), large
  • disabled: boolean
Enviar
<dm-button variant="primary" size="large">Enviar</dm-button>

dm-card

Cartão de conteúdo com suporte opcional a imagem de topo.

Atributos:

  • image-src: URL da imagem
  • image-alt: texto alternativo da imagem

Título do card

Texto descritivo do conteúdo.

<dm-card image-src="https://via.placeholder.com/640x240" image-alt="Exemplo de imagem">
  <h4>Título do card</h4>
  <p>Texto descritivo do conteúdo.</p>
</dm-card>

dm-floating-input

Campo de entrada com label flutuante e estados de foco.

Atributos:

  • label: texto do rótulo
  • type: text, email, password, tel, number, url
  • name, value, placeholder
  • disabled, required, readonly
<dm-floating-input label="Email" type="email" name="email" />

dm-carousel

Carrossel de imagens com navegação automática e manual.

Atributos:

  • interval: intervalo de transição automática em milissegundos (padrão: 5000)
  • autoplay: ativa/desativa reprodução automática (padrão: true)
<dm-carousel interval="5000">
  <dm-carousel-slide image="url" title="Título" description="Descrição"></dm-carousel-slide>
  <dm-carousel-slide image="url" title="Título 2" description="Descrição 2"></dm-carousel-slide>
</dm-carousel>

dm-modal

Diálogo modal com título, escuta de Escape e fechamento no overlay.

Atributos:

  • open: define se o modal está visível
  • title: texto do cabeçalho
Visualizar Modal
<dm-modal id="myModal" title="Aviso">
  <p>Este é o conteúdo do modal.</p>
</dm-modal>

<script>
  const modal = document.getElementById('myModal');
  modal.show();
</script>

Este é o conteúdo do modal.

dm-navbar

Barra de navegação responsiva com variante de estilo e menu mobile integrado.

Atributos:

  • brand: texto exibido como nome do projeto
  • variant: default, dark, primary, minimal
HomeDocsSobreContato
<dm-navbar brand="Meu App" variant="primary">
  <a href="#home">Home</a>
  <a href="#docs">Docs</a>
  <a href="#about">Sobre</a>
  <a href="#contact">Contato</a>
</dm-navbar>

dm-toast

Notificação temporária com variantes de estado.

Atributos:

  • variant: success, warning, danger, info
  • duration: tempo em milissegundos antes de fechar automaticamente
Visualizar Toast
<dm-toast-container id="toast-root"></dm-toast-container>
<script>
  const root = document.getElementById('toast-root');
  root.show('Mensagem enviada', 'success', 4500);
</script>

dm-toggle

Interruptor de seleção para estados booleanos.

Atributos:

  • checked: estado ativado
  • disabled: desativa o controle
  • name: nome do campo de formulário
  • value: valor enviado quando marcado
  • label: texto opcional exibido ao lado
<dm-toggle label="Ativar modo escuro" checked value="dark" />
